# Studio speech setup
Speech UI is in /creative. This integration is not active without provider configuration.
Set ELEVENLABS_API_KEY as a native Sites secret, ELEVENLABS_VOICE_ID to an approved voice from that account, optional ELEVENLABS_VOICE_NAME, and VOICE_OWNER_ID to the authenticated owner's exact Sites user ID. Never put secrets in source or browser storage. Deploy to apply runtime configuration.
The endpoint rejects anonymous and non-owner generation; max 1000 characters per explicit click. Provider model eleven_v3, MP3 44.1kHz 128kbps. No automatic retries. Provider billing limits must be configured in the provider account before enabling; this is not a global spend cap or multi-customer billing system.
The script is sent to ElevenLabs only on Generate. Audio remains in browser session and can be downloaded or used by the existing video renderer. Uploaded local audio still works. Review actual Moroccan pronunciation before commercial use. No real speech generation has been verified without a funded provider account.

## Google option
Set GEMINI_API_KEY as a native Sites secret from a user-approved Gemini project. No key has been configured yet. The Google option uses the documented REST interactions endpoint, gemini-3.8-flash-lite-tts, Kore, speech_metadata for Moroccan delivery, and validates WAV output before returning it. UI chooses Google by default and does not fall back to ElevenLabs. It cannot enforce Google's free-tier billing: inspect the selected project's actual quota and billing before sending a real request. Free-tier content may be used to improve Google products. No actual Google audio generation or browser UI verification was completed because the browser entered protected credential state.
